## Lit 3 grid time picker. Compatible with Web Awesome 3.  

AM hours in the first two rows, PM hours in the
        next two, minute tiles in their own right-hand column - the same
        layout as the legacy jQuery UI Timepicker Add-on written by the community several years ago.

This version uses Web Awesome classes for styling and layout, as much as possible.

Usage:
```
<wa-time-grid-input
          label="Meeting time"
          hint="Pick an hour, then a quarter hour."
          value="8:00 AM"
          with-clear
        ></wa-time-grid-input>```
        
        Use `minute-interval` to change the minute step (default 15).

Please see the examples in the demo html file.
